This project includes the code used to generate and analyze radial SFRs in AGN and control galaxies from the SDSS MaNGA Survey. 

Server Data is to be run on Sciserver using their Marvin module as Marvin doesn't work properly on windows. 

My Side 474 Notebook is the local data processing and the code to generate the radial SFRs and the plots for the project. 

Radial (1) is the calculated radial profiles for every all 1860 galaxies included in the final AGN and Control samples along with their IDs.

The image data, H alpha maps, and galaxy properties can all be made from the Sciserver code (and a few sections of the local code) but haven't been included here as they are nearly exact copies of data from the SDSS database.
